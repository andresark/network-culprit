First public MIT-licensed release of Network Culprit for Apple Silicon and macOS 27.

- Native SwiftUI dashboard with Liquid Glass, a color-coded menu bar icon, and local diagnostic history.
- Separate local network, internet/ISP path, DNS/NextDNS, Tailscale, IPv6 prefix, and web/TLS evidence.
- Optional launch at login and debounced native issue/recovery notifications with observed duration.
- Optional bandwidth benchmarks, charts, and JSON/CSV exports.
- Public builds contain no personal resolver defaults, network histories, or developer source paths.
- Scheduled vulnerability auditing, SHA-pinned actions, Dependabot update PRs, and tested release builds.

**Requires macOS 27 or later and Apple Silicon.** The app is ad hoc signed and is not Apple notarized. See the README for installation and privacy information. Keep macOS updated for Apple framework, Swift runtime, and system SQLite security fixes.
